📷 Analizador de Imágenes de Productos

Demo: Sube una foto, nuestro OCR inteligente devuelve información del producto

🎯 ¿Qué es esta funcionalidad?

Esta es una demostración de visión por computadora que permite a tus clientes o usuarios:

📸 Subir Foto

El usuario toma una foto de un producto con su cámara o selecciona una imagen.

🤖 IA Analiza

Nuestro backend usa OpenAI Vision API para interpretar la imagen.

📊 Extrae Datos

OCR detecta: nombre producto, marca, precio, código barras, características.

✅ Devuelve Info

Los datos se muestran en tiempo real para que el usuario los use.

🛒 Integración

Se puede integrar con carrito de compras o análisis de competencia.

📱 Mobile Ready

Funciona perfectamente en celulares con cámara integrada.

⚙️ Cómo Funciona (Técnico)

1️⃣ Frontend - Envío de Imagen

El usuario sube la imagen a través de la interfaz. Se envía como FormData al servidor:

const formData = new FormData(); formData.append('image', file); fetch('/api/analyze-product-image', { method: 'POST', body: formData }) .then(res => res.json()) .then(data => console.log(data.analysis));

2️⃣ Backend - Análisis con OpenAI

El servidor recibe la imagen, la convierte a base64 y la envía a la OpenAI Vision API:

const openai = new OpenAI(); const response = await openai.chat.completions.create({ model: "gpt-4-vision", messages: [{ role: "user", content: [ { type: "image_url", image_url: { url: `data:image/jpeg;base64,${base64Image}` } }, { type: "text", text: "Analiza este producto y devuelve JSON con..." } ] }] });

Endpoint del servidor:

POST /api/analyze-product-image Content-Type: multipart/form-data - image: [archivo de imagen] // Archivo: src/image-analysis-routes.js

3️⃣ Respuesta JSON

El servidor devuelve un JSON con toda la información extraída:

{ "ok": true, "analysis": { "producto_nombre": "Coca-Cola 2L", "descripcion": "Bebida carbonatada de cola", "marcas_detectadas": ["Coca-Cola", "The Coca-Cola Company"], "precio_visible": "Q15.99", "codigo_barras": "5449000050127", "caracteristicas": [ "Volumen: 2 litros", "Carbonatada", "Refrigerar después de abrir", "Hecho en Guatemala" ], "recomendaciones": "Producto muy conocido...", "confianza": "alta" } }

📥 Cómo Instalar en tu Proyecto

  1. Instalar dependencia:
    npm install multer
  2. Agregar archivo de rutas: Usa src/image-analysis-routes.js
  3. Importar en server.js:
    import imageAnalysisRoutes from "./image-analysis-routes.js"; app.use('/api', imageAnalysisRoutes);
  4. Incluir script en HTML:
    <script src="/js/product-image-analyzer.js"></script>
  5. Configurar OpenAI API:

    Asegúrate de tener OPENAI_API_KEY en tu archivo .env
